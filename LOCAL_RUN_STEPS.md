# Run Kronos Locally

These steps run Kronos-small on a local NVIDIA GPU and forecast prices from a CSV file. The recommended settings for an RTX 5060 with 8 GB VRAM are CUDA, a 512-row context, and one forecast sample.

## 1. Open the repository

```powershell
cd C:\Github\Kronos
```

## 2. Create and activate a virtual environment

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

If PowerShell blocks activation, run this once in the same PowerShell window:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

## 3. Verify PyTorch can see the GPU

```powershell
python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CUDA unavailable')"
```

The first result should be `True`. Install a CUDA-enabled PyTorch build if it is `False`; use the command generated by the [official PyTorch selector](https://pytorch.org/get-started/locally/).

## 4. Download the models

The first prediction can download models from Hugging Face automatically. To download them first and reuse the local cache:

```powershell
python download_models.py
```

The models used by the file prediction script are `NeoQuasar/Kronos-Tokenizer-base` and `NeoQuasar/Kronos-small`.

## 5. Prepare the input CSV

The file must contain these columns:

```text
timestamps,open,high,low,close
2024-06-18 11:15:00,11.27,11.28,11.26,11.27
```

`volume` and `amount` are optional. The default command uses 400 rows as context and predicts the next 120 timestamps, so the CSV must contain at least 520 rows. The OHLC values in the forecast range are not used; only their timestamps are used as the forecast index.

## Getting market data

### Option A: Yahoo Finance

Yahoo Finance is convenient for stocks, ETFs, indices, and many futures. Install the optional client:

```powershell
python -m pip install yfinance
```

Save this as `download_yahoo.py` and change `SYMBOL` and `INTERVAL` as needed:

```python
import yfinance as yf

SYMBOL = "AAPL"
INTERVAL = "1d"

data = yf.download(
    SYMBOL,
    period="2y",
    interval=INTERVAL,
    auto_adjust=False,
    progress=False,
)
data = data.reset_index()
data.columns = [str(column).lower() for column in data.columns]
data = data.rename(columns={"date": "timestamps", "datetime": "timestamps"})
data["amount"] = data["close"] * data["volume"]
data[["timestamps", "open", "high", "low", "close", "volume", "amount"]].to_csv(
    "market_data.csv", index=False
)
```

Run it and inspect the result:

```powershell
python download_yahoo.py
Get-Content market_data.csv -TotalCount 3
```

Yahoo usually provides daily data reliably. Intraday history is more limited, so use a different source if you need a long 5-minute history.

### Option B: Binance public crypto data

For crypto, Binance provides public candlestick data without an API key. Install `requests`:

```powershell
python -m pip install requests
```

Save this as `download_binance.py`:

```python
import requests
import pandas as pd

SYMBOL = "BTCUSDT"
INTERVAL = "1h"
LIMIT = 1000

url = "https://api.binance.com/api/v3/klines"
rows = requests.get(
    url,
    params={"symbol": SYMBOL, "interval": INTERVAL, "limit": LIMIT},
    timeout=30,
).json()

columns = [
    "open_time", "open", "high", "low", "close", "volume",
    "close_time", "quote_volume", "trades", "taker_buy_base",
    "taker_buy_quote", "unused",
]
data = pd.DataFrame(rows, columns=columns)
data["timestamps"] = pd.to_datetime(data["open_time"], unit="ms")
data["amount"] = data["quote_volume"].astype(float)
data[["timestamps", "open", "high", "low", "close", "volume", "amount"]].to_csv(
    "market_data.csv", index=False
)
```

Run it with:

```powershell
python download_binance.py
```

### Other easy sources

- **Your broker or exchange export:** export candle/K-line data as CSV, then rename the columns to `timestamps`, `open`, `high`, `low`, `close`, `volume`, and `amount`.

#### Alpha Vantage

Alpha Vantage is useful for equities and forex. Create a free API key at [alphavantage.co](https://www.alphavantage.co/support/#api-key), then install the client:

```powershell
python -m pip install alpha_vantage
```

Save this as `download_alpha_vantage.py`, replace `YOUR_API_KEY` and `SYMBOL`, and run it:

```python
from alpha_vantage.timeseries import TimeSeries

SYMBOL = "AAPL"
API_KEY = "YOUR_API_KEY"

client = TimeSeries(key=API_KEY, output_format="pandas")
data, _ = client.get_daily(symbol=SYMBOL, outputsize="full")
data = data.rename(columns={
    "1. open": "open",
    "2. high": "high",
    "3. low": "low",
    "4. close": "close",
    "5. volume": "volume",
})
data.index.name = "timestamps"
data = data.reset_index()
data["amount"] = data["close"] * data["volume"]
data[["timestamps", "open", "high", "low", "close", "volume", "amount"]].to_csv(
    "market_data.csv", index=False
)
```

```powershell
python download_alpha_vantage.py
```

Free-tier requests are rate-limited, so download once and reuse the CSV locally.

#### Polygon.io

Polygon.io provides US stock aggregates and requires an API key. Create an account at [polygon.io](https://polygon.io/), set the key in PowerShell, and install the client:

```powershell
$env:POLYGON_API_KEY = "YOUR_API_KEY"
python -m pip install polygon-api-client
```

Save this as `download_polygon.py` to download daily AAPL candles. Change the ticker and dates as required:

```python
import os
import pandas as pd
from polygon import RESTClient

client = RESTClient(os.environ["POLYGON_API_KEY"])
bars = client.get_aggs("AAPL", 1, "day", "2023-01-01", "2025-01-01", limit=50000)
data = pd.DataFrame([
    {
        "timestamps": bar.timestamp,
        "open": bar.open,
        "high": bar.high,
        "low": bar.low,
        "close": bar.close,
        "volume": bar.volume,
    }
    for bar in bars
])
data["timestamps"] = pd.to_datetime(data["timestamps"], unit="ms")
data["amount"] = data["close"] * data["volume"]
data.to_csv("market_data.csv", index=False)
```

```powershell
python download_polygon.py
```

Use `1, "hour"` or `5, "minute"` instead of `1, "day"` for intraday bars when your Polygon plan supports that history.

#### Stooq

Stooq is a simple source for free end-of-day data and does not require an API key. For example, download Apple data directly in PowerShell:

```powershell
Invoke-WebRequest `
    -Uri "https://stooq.com/q/d/l/?s=aapl.us&i=d" `
    -OutFile stooq_aapl.csv
```

Convert the Stooq columns to the Kronos format with this Python script:

```python
import pandas as pd

data = pd.read_csv("stooq_aapl.csv")
data = data.rename(columns={"Date": "timestamps"})
data["volume"] = data.get("Volume", 0)
data["amount"] = data["close"] * data["volume"]
data[["timestamps", "open", "high", "low", "close", "volume", "amount"]].to_csv(
    "market_data.csv", index=False
)
```

```powershell
python convert_stooq.py
```

For other instruments, replace `aapl.us` with the appropriate Stooq symbol. Stooq is generally end-of-day, so it is best suited to daily forecasting.

Regardless of source, keep one instrument and one consistent interval per file. Sort rows from oldest to newest, remove duplicate timestamps, and check that prices and timestamps are not missing.

## 6. Run a prediction

```powershell
python examples\predict_file.py C:\path\to\market_data.csv --output prediction.csv
```

The script uses `cuda:0`, `max_context=512`, `Kronos-small`, and `sample_count=1`. Adjust the context and horizon when needed:

```powershell
python examples\predict_file.py C:\path\to\market_data.csv `
    --lookback 400 `
    --pred-len 120 `
    --sample-count 1 `
    --output C:\path\to\prediction.csv
```

Use CPU only when CUDA is unavailable:

```powershell
python examples\predict_file.py C:\path\to\market_data.csv --device cpu
```

## 7. Inspect the result

`prediction.csv` contains the predicted `open`, `high`, `low`, `close`, `volume`, and `amount` columns indexed by `timestamps`.

For a built-in plotting example, see [examples/prediction_example.py](examples/prediction_example.py). For the model API and batch prediction details, see [README.md](README.md).

## Limitations

This is a forecasting model, not a trading system or financial advice. Validate data quality, market calendars, slippage, transaction costs, and risk controls before using forecasts for any trading decision. Fine-tuning requires substantially more GPU memory than inference and is not covered by this quick-start flow.
